# 3A 数字启蒙设计

日期：2026-10-20。状态：用户已确认设计及实施计划，实施与验收记录见 docs/phase-3a-status.md。

## 目标与范围

延续网页版复刻项目，面向儿童与陪读家长，让数字、数量和加减变化可以直接观察和操作。首批开放现有 numbers、count、plus-block、minus-block 四个入口。原站本轮访问失败，以下是已确认范围下的项目交互设计，不宣称精确复刻其运算规则。

保留 Flutter/GetX、Android/iOS、本地资源、全部 241 个既有 ID 与 learning_state_v1。首批新增 11 个数字认读条目，合计 252 个条目、20 个开放入口。三个互动工具不制造学习条目，不计入总量或已学数量。百数表、九九运算表、绘本、对话、画板继续保留待开放状态。

## 方案取舍

采用一个 math 模块内的四种明确页面，共用数量图形和纯 Dart 运算规则。数字认读接入原有条目与进度；互动页只保存页面内操作状态。

不将三类互动工具伪装为认读课程，否则会引入无明确含义的已学标记和分母；不在首批加入随机答题引擎，否则会扩大到题库、答案校验与练习记录。上述功能可在后续有明确需求时独立设计。

## 四个入口

### 学数字

目录按数值顺序展示 0～10，稳定 ID 为 number-0 至 number-10。每项包含阿拉伯数字、中文名称、中文名称注音和数量图示；0 用空的数量区域及“一个也没有”解释，不用一个装饰物表达零。

标题和主数字分开呈现：现有 text/pinyin 保存“零、一、二……十”及对应拼音，新增整数 numberValue 为实际数值，避免把拼音错误绑定到阿拉伯数字字符。目录可搜索数字或中文名称，顺序固定为数值升序，不使用汉字笔画排序。支持上一项、下一项、继续学习及手动标记/撤销，复用 LearningStore 的 numbers cursor。

首批不新增录音：audio=null、audioQuality=unavailable，显示现有暂缺录音说明。语音未交付不能影响看图学习，也不新增运行时 TTS 或生成未经确认的音频资产。

### 数个数

默认展示 5 个同类、由代码绘制的物体；通过带名称的加减按钮调整目标数量，范围 1～10，越界按钮禁用。物体以稳定位置排列，点击尚未计数的物体时给予边框和序号，显示“已经数了 x 个”。再次点击同一个物体不重复累计，也不取消它；“重新数”清除计数标记，保留当前数量。改变数量时清除旧标记。

全部点完提示“一共有 n 个”，不判分、不自动标记学会。物体有“第 k 个，未数/已数”的读屏说明；颜色之外同时使用序号区分状态。

### 可视化加法

默认 2+3，两个操作数均为整数 0～10，且和不超过 10。分别调整两组数量，非法增加禁用。先显示两组和算式“a+b=？”，点击“合在一起”后展示总数量与结果；左组、右组采用不同颜色并辅以标签，结果保留来源分组的可辨识性。

改变操作数即回到未揭示状态；“重新演示”保留操作数并隐藏结果。0+0、0+n 与 n+0 均能正确显示空组。首批使用明确的前后状态，无需依赖计时动画完成才能操作。

### 可视化减法

默认 5−2，被减数 0～10，减数 0～被减数。选择总数量和拿走数量后，先显示 a 个物体；点击“拿走几个”将末尾 b 个物体加删除线并降低强调，显示 a−b=a−b 的数值结果和剩余数量。被拿走物体仍留在图中解释过程，不参与剩余计数。

改变被减数时将超过新上限的减数收敛到新被减数；改变任一参数都隐藏结果。“重新演示”保留参数并恢复物体。覆盖 0−0、n−0、n−n，不允许负数。

## 数据与路由

扩展 ContentKind.number 用于 11 个认读条目，整数 numberValue 必须在 0～10 且唯一，ID 与数值对应。互动分类通过新增可选 activityKind 区分 count/addition/subtraction；可用分类须且只能提供内容 kind 或 activityKind。旧 JSON 的缺省值与既有类型推导不变，互动分类不能拥有普通条目。

LearningCategory 解析 activityKind，LearningItem 解析可选 numberValue。内容校验、生成器与审计同步接受并约束新结构，禁止仅手工编辑生成输出。保存一份既有 241 项 ID fixture，新增检查同时验证旧条目、阅读 revision、资源引用不变。

首页按分类类型分派：numbers 继续使用 /learn/numbers，数字详情使用现有学习路由并按类型渲染；三个互动入口使用 /math/:categoryId，仅允许已开放且具有正确 activityKind 的分类。直接访问未知或非互动分类回到首页，不创建空控制器。每次进入互动页恢复默认值，退出销毁临时状态，重启不承诺恢复未完成操作。

所有学习页面切换仍经过现有音频路由观察器，不能留下阅读页旧队列。互动页不创建 AudioPlayer，不写 learned/cursors。数字页面的持久化失败使用既有反馈，不能显示未保存的成功状态。

## 布局与可访问性

数量最多 10 个，使用响应式 Wrap/网格与滚动布局，不用固定屏幕坐标。内容最大宽度沿用现有规范；大数字、文字、控件服从系统字体缩放。每个可点击物体和按钮至少 48×48 逻辑像素；操作数同时提供数值与中文语义。

0 的空区域有可见文字，不把装饰元素计算在内；分组标签、序号和删除线保证不只依赖颜色。全局拼音开关作用于数字中文名称，操作说明保持可读，不为整个交互文案强制逐字注音。保留主题、返回和离线模式。

## 验收

1. 纯 Dart 测试穷举合法加减组合及非法输入；加法和不超过 10，减法不为负，参数变更重置展示；数数对重复点击幂等。
2. 数据测试确认 252 项、20 个开放入口、11 个数字与三类互动配置；原 241 个 ID 和 21 篇阅读引用保持完整。
3. 状态测试覆盖数字 cursor、标记、重启恢复、写入失败；所有互动操作不改变已学集合和进度键。
4. Widget 测试走通四个入口、0 的图示、边界禁用、重置、返回、直接路由与失效路由；320px/200% 字号和平板无溢出，语义可识别。
5. 执行格式化、静态分析、Flutter/Python 全套测试、生成器 --check、联合资源审计和 Android/iOS 构建；iOS 模拟器操作四入口并重启检查旧新进度。Android 若仍无设备则只报告构建，保留原设备验收缺口。
6. 更新 README、路线图、3A 交付记录和截图，区分功能、构建和设备验证。既有教学听审与 Android/PDF 补验不因本阶段结束而被标记完成。

## 实施边界

不新增运行时依赖、在线服务、随机题库、积分、排行榜、自动评估或练习持久化。不操作继承自用户主目录的 Git，不提交或创建主目录 worktree。设计批准后再编写实施计划，明确文件、测试和生成顺序。
