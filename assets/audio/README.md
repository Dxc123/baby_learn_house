# 离线示范音频

由 macOS 系统 Tingting 中文语音合成，生成脚本：tool/generate_sample_audio.py。
第一阶段的 16 个 WAV 已保留。2A 新增 82 个词语/英文字母示范，共 98 个随包 WAV；新增脚本为 tool/generate_phase2_audio.py，字母名称使用 Samantha 英语语音。
这些文件不从原站下载，不需要联网播放。另有 57 项拼音暂缺录音，不用汉字合成替代它们。

这些音频是开发示范，不是专业拼音教学录音。单韵母通过同音汉字合成；
尤其 o 的口音、音长及声调需要教学校对，正式发布前应替换为获授权、
逐条审核的标准普通话录音，并核对合成语音的分发使用条件。

逐条来源和质量标识见 manifest.json；当前全部为 demo，reviewedBy 为空，没有把合成音频标为已审核。
